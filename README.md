# Weather Data Pipeline

## Project Overview
This project collects current weather data for cities using the Open-Meteo API and combines it with population data.

## Technologies
- Python
- Pandas
- Open-Meteo API
- Google BigQuery
- SQL
- Looker Studio

## Features
- Collects weather data for 125 cities
- Combines weather and population information
- Uploads data to Google BigQuery
- Creates a SQL view to identify the hottest large-population cities
- Supports dashboard visualization in Looker Studio

## Setup
Install the required packages:

pip install -r requirements.txt

## Security
Do not upload API keys, service-account JSON files, or other credentials.
